Preguntas frecuentes

Todo lo que necesitas saber

¿Cómo realizo un pedido? {% icon "expand_more" "faq__arrow" %}

Entra al catálogo, elige el producto, revisa su disponibilidad y completa el formulario de pedido en el detalle del producto.

¿El stock que aparece es real? {% icon "expand_more" "faq__arrow" %}

Sí. El catálogo se alimenta directamente del inventario, por lo que la disponibilidad se actualiza en tiempo real.

¿Puedo comprar sin crear una cuenta? {% icon "expand_more" "faq__arrow" %}

Sí. El catálogo y el formulario de pedido son públicos. Las cuentas se reservan para el equipo que administra la tienda.

¿Cómo se protege mi sesión? {% icon "expand_more" "faq__arrow" %}

El inicio de sesión usa tokens JWT emitidos por la API y almacenados del lado del servidor, sin exponerlos al navegador.

¿Qué pasa si un producto está agotado? {% icon "expand_more" "faq__arrow" %}

El producto seguirá visible con la etiqueta “Agotado”, pero no permitirá registrar nuevos pedidos hasta que se reponga el stock.
